# nasa-engine-failure-predictor

This project will use real turbofan engine sensor data from NASA's CMAPSS dataset to see signs of mechanical failure before it happens

## The problem
When a mechanical failure occurs within an aircraft's engine, it can be very dangerous and expensive. One challenge that often happens within aerospace and defensive engineering is predicting these failures and flagging them before it happens using sensor data.

## What this does
- Loads NASA CMAPSS data from real engine tests
- Plots the data over engine cycles
- Identify sensors that have consistent patterns when the engine is failing
- Flag these failures

## Tools used
Python | pandas | NumPy | matplotlib
